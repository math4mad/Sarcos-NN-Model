What does a small MLP actually learn from SARCOS?

An SVD study of layer weight matrices, with a warning about the published split

measurement test MSE (normalised per joint) seeds
selected model, full rank (8 seeds) 0.0161 8
same net, every layer truncated to rank 128 *leading* 0.0177 (energy 0.962) 8
same net, rank 128 *middle* 0.9974 (energy 0.433) 8
read-out layer alone, energy-matched at 0.5: *middle* 0.2329 (energy 0.550) 8
read-out layer alone, energy-matched at 0.5: *leading* 0.6307 (energy 0.553) 8
1.0 = predicting the train mean. Full tables, per-joint numbers and the split forensics are in the results note.

1 The short version

Warning

The leading singular directions carry the learning effect. Keep the top 128 directions of every layer and the net is barely damaged; keep an equal-rank slice of the bulk or the tail and it is no better than a constant predictor — even while holding a third of the Frobenius energy. Retained energy does not predict function, so any low-rank claim must report both.

The one exception is the read-out layer (7 × width): there, at matched energy, the middle band beats the leading band. That was the README’s original hypothesis, and it survives only in that one place — replicated across 8 seeds with non-overlapping per-seed ranges.

2 What is in here

  1. Results note — the whole study as an executable Quarto note: hypothesis, split forensics, baseline, rank sweeps, iso-energy sweeps, per-layer ablations, the trained-under-constraint regime, validity checks. Every table is generated from results/summary.json and the run records at render time, so the prose cannot drift from the runs.
  2. The README in the repository carries the same tables in compact form, plus the experiment plan and the rules the study is run under.

3 The forensics nobody asked for

The published GPML test file is every 10th row of the published training file, and still inside it — 98.2% of its rows occur verbatim in train. Rows are also in trajectory order, so a row-wise random split leaks too (0.0207 vs 0.0248 vs 0.0357 test MSE for row-wise / 256-row / 4096-row block sizes on the same net). The split is therefore defined once, in src/sarcos_svd/data.py, as a seeded permutation of contiguous row blocks, and recorded in every run.

4 Reproduce

pip install -r requirements.txt && pip install -e .
python -m sarcos_svd.data --fetch --report
python -m sarcos_svd.train --seed 13 --block-size 256 --fractions .8 .1 .1 \
    --hidden 256 256 --mode full --epochs 60
python -m sarcos_svd.evaluate --run results/runs/<run_id>/run.json \
    --layers all --sweep 1,2,4,8,16,32,64,128 --plot
python -m sarcos_svd.report --out results/summary.json
python -m sarcos_svd.publish            # builds this site onto the gh-pages branch
